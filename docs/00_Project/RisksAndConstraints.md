## Core Constraints

### Budget Constraint

1件の研究実行について、事前に最大費用または最大トークンを指定できる設計にする。

### Iteration Constraint

自動反復には明示的な最大回数を設定する。終了条件のない討論は許可しない。

### Evidence Constraint

AI間の合意数を証拠の強さとして扱わない。証拠評価は出典の種類、直接性、再現性、更新日、反証の有無に基づく。

### Human Authority Constraint

Mission変更、外部公開、課金、高リスク領域への適用、秘密情報の送信は人間の明示的判断を必要とする。

### Reproducibility Constraint

最低限、以下を記録する。

- 実行日時
- 使用モデルとバージョン
- システム／役割プロンプトの版
- 温度等の主要パラメータ
- 入力資料
- 各工程の出力
- トークン量・費用・処理時間
- 最終評価
